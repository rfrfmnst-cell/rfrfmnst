# العلامات الصينية في سوق السعودية — 18 أكتوبر 2026

أضيفت 50 علامة إلى دليل اختيار المركبة، مع البحث بالعربية والإنجليزية والتهجئات الشائعة ومرشح مستقل للعلامات الصينية. يشمل التجميع MG ذات المنشأ البريطاني والملكية الصينية؛ ولا يعيد تصنيف Volvo أو غيرها تلقائيًا بسبب الملكية. JMC الصينية منفصلة عن GMC الأمريكية. Skyworth/Skywell بطاقة واحدة مع الاسم البديل لمنع التكرار.

تم التحقق من الحضور المحلي من مواقع الشركات والوكلاء وموردي قطع الغيار المحليين أدناه. هذا دليل اختيار لطلب القطعة، وليس تعدادًا حكوميًا كاملًا أو وعدًا بتوفر المخزون أو الوكالة لكل طراز. الطرازات اقتراحات إدخال؛ الفئة يكتبها المستخدم أو يختار عدم معرفتها، دون اختراع مطابقة أو فئات لكل سنة. المعدات تعرض أنواع المعدة مع خيار إدخال موديلها يدويًا.
