- ثبت في آخر فحص أن API العامة تقدم صفحة PHP الافتراضية، وأن صفحة دخول العميل تعرض عدم الإتاحة. السبب التفصيلي لإعداد hPanel غير محسوم.
- ما زال مصدر قاعدة الأعمال الفعلي واعتماده الآمن غير متاحين. Supabase المتصل للتكاملات؛ لا تنشئ فيه جداول بديلة.
- ربط إدارة Hostinger لم يكتمل. تعريف MCP المحلي موجود، لكن OAuth انتهى بمهلة في المحاولة السابقة. فتح `https://mcp.hostinger.com/` مباشرة في المتصفح أعاد 405؛ هو عنوان خدمة MCP وليس صفحة ويب لتسجيل الدخول.
- عند الاستئناف: تحقق من حالة مصادقة الموصل وأدوات الاستضافة المتاحة أولًا. لا تعاود إرسال روابط OAuth ذات رجوع localhost من بيئة بعيدة قبل التأكد من دعم مسار الرجوع. إذا بقي الربط متعذرًا، حدد التطبيق وطريقة الاتصال التي يدعمها قبل إعطاء خطوات إعداد إضافية.
- بعد إتاحة الاتصال: افحص ربط API ونوع التطبيق والـentry وBuild/Runtime، ثم وجود وصلاحية متغيرات قاعدة البيانات والجلسات دون إظهار قيمها؛ نفذ قراءة فقط على القاعدة الأصلية وStaging المعتمدة عند توافرهما.
