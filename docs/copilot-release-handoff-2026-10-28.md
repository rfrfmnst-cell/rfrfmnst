## المتبقي إلى Copilot

1. افتح فرع المراجعة في VS Code واختر `Rafraf Developer`، وراجع التقرير
   واختبارات الأداة قبل تعديل الملفات نفسها بالتوازي.
2. أتم اتصال Hostinger واقرأ إعدادات المواقع الأربعة وسجلات البناء دون
   عرض الأسرار. حدد سبب API 404 ومصدر الإصدار المنشور فعليًا.
3. جهز الحزم وخطة الرجوع من المصدر الصحيح، مع Node 24 و`pnpm run build`
   ونقطة دخول Hostinger الموثقة. صاحب المشروع طلب النشر والاختبار؛ اربط
   الإجراء بالموارد الصحيحة ولا تعتبر دمج GitHub نشرًا للاستضافة.
4. أعد فحص القبول مع SHA المنشور، ثم اختبر الدخول وملكية الطلبات وعزل
   الموردين بحسابات اختبار مخولة.
5. أكمل إعدادات الحسابين واختبار sandbox. قبول Tap الحي يبقى مغلقًا حتى
   الاسترداد والمصالحة واختبار القبول؛ فحص OTO لا يصدر بوليصة أو شحنة.

النشر الفعلي واختبار الحسابين متوقفان على اتصال الاستضافة والأسرار
الصحيحة، ولم يُستبدلا بادعاء نجاح.
