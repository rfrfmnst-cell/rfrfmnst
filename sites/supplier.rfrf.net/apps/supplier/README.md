# بوابة المورد

واجهة المورد لتوثيق الحساب ومراجعة طلبات التسعير وإرسال العروض ضمن سياسات
المخاطر والتوافق.

التسجيل إلكتروني ومتاح للمنشآت الدولية: اسم المنشأة، الدولة، رقم التسجيل
القانوني، وجوال دولي ثم OTP. يبقى الحساب `PENDING` حتى يرفع المورد سجلًا أو
رخصة تجارية صادرة في بلده، أو وثيقة عمل حر حيث تنطبق، وتعتمدها الإدارة. لا
يتطلب المسار عقد API مع رفرف ولا يمنح صلاحية التسعير قبل المراجعة.

```bash
pnpm --filter supplier dev
pnpm --filter supplier check-types
pnpm --filter supplier lint
pnpm --filter supplier build
```

- المنفذ المحلي: `3002`
- فحص الجاهزية: `GET /api/readiness`
- OTP الإنتاجي يستخدم مزود التسليم المحدد في الكود والبيئة؛ أي تغيير مزود
  يجب أن يمر عبر Preview وsmoke test حقيقي قبل الترقية.
